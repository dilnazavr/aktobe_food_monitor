# Монитор СЗПТ — Актобе (Госзакупки)

Небольшой Flask-сайт + скрапер, который ищет **завышенные цены** на социально значимые продукты питания в государственных закупках **Актюбинской области**.

## Что умеет

- Ищет закупки продуктов из списка СЗПТ только по Актобе
- Сравнивает цену с эталонной
- Показывает лоты, где цена выше эталона на **40% и больше**
- Красивый тёмный интерфейс
- Запуск проверки прямо с сайта (в фоне)

## Быстрый старт

```bash
cd aktobe_food_monitor
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt

python app.py
```

Открой в браузере: http://127.0.0.1:5000

## Важно

- Пока работает **без официального API** (через HTML-парсинг).
- Между запросами стоит пауза ~1.8 сек, чтобы не нагружать сайт.
- Результаты зависят от текущей вёрстки goszakup.gov.kz.
- Когда получишь API — можно будет сильно ускорить и сделать точнее.

## Настройки (config.py)

- `THRESHOLD_PERCENT = 40` — порог «подозрительно»
- `MAX_LOTS_PER_PRODUCT = 6` — сколько лотов проверять на продукт
- `KATO_AKTOBE = "150000000"` — код региона
